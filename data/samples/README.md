# Demo Samples

These 10 PNG images (2 per class across 5 astronomical categories) are **synthetic demo samples** generated procedurally for demonstration purposes only.

**Not the full test set.** Do not cite accuracy from these alone. They are not part of the held-out test split.

Full evaluation requires downloading the real dataset (`python src/prepare_data.py`) and running `src/evaluate.py` on the test split.

Classes: Spiral Galaxy, Elliptical Galaxy, Nebula, Star Cluster, Planetary Object
